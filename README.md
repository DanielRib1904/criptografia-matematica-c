# criptografia-matematica-c
# Projeto de Criptografia Matemática em C

**Disciplina:** Algoritmo e Pensamento Computacional  
**Professor:** Francisco de Assis Cavallaro

## Objetivo

Desenvolver um programa em linguagem C que utilize criptografia simples, progressões matemáticas e conceitos fundamentais de programação.

## Funcionamento

O programa solicita uma palavra de até 15 letras, um valor de SHIFT e uma sequência matemática. Em seguida, combina a cifra de César com os valores da sequência escolhida para produzir uma palavra criptografada.

## Sequências matemáticas

- **PA:** progressão aritmética, com valores 1, 3, 5, 7...
- **PG:** progressão geométrica, com valores 1, 2, 4, 8...
- **Fibonacci:** sequência 1, 1, 2, 3, 5...
- **Números primos:** sequência 2, 3, 5, 7, 11...

## Tecnologias utilizadas

- Linguagem C
- Variáveis e funções
- Estruturas condicionais
- Laços de repetição
- Manipulação de caracteres
- Manipulação de arquivos

## Arquivos gerados

- `resultado_criptografia.txt`: armazena o resultado da criptografia.
- `log_execucao.txt`: registra informações sobre cada execução.

## Taxonomia de Bloom

- **Lembrar:** reconhecer letras e valores ASCII.
- **Compreender:** entender a cifra de César e as sequências matemáticas.
- **Aplicar:** implementar os algoritmos em C.
- **Analisar:** comparar os resultados das sequências.
- **Avaliar:** discutir os padrões e as limitações da criptografia.
- **Criar:** integrar os conceitos em um único programa.

## Limitações

Este projeto tem finalidade didática. A cifra utilizada não oferece segurança adequada para proteger informações confidenciais.

## Conclusão

A atividade demonstra a integração entre algoritmos, matemática aplicada, criptografia simples e manipulação de arquivos em linguagem C.
